# Amira Gharbi — Portfolio

Personal portfolio built with React, TypeScript, and Vite. Luna is an offline portfolio assistant with a local knowledge base, so it does not require an API key or network connection to answer profile questions.

## Run Locally

**Prerequisite:** Node.js


1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`
3. Open the local URL printed by Vite (usually `http://localhost:3000`).
